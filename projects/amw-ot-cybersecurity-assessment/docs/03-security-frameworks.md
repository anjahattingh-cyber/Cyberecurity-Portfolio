Security Frameworks

Overview: 
Several established cybersecurity frameworks and principles were applied to the AMW environment to support risk management, security planning and protection of critical IT and OT systems. 

NIST Cybersecurity Framework 2.0 

The NIST Cybersecurity Framework (CSF) 2.0 was applied across the AMW environment using its core functions: 

| Function | Application to AMW | 
| --- | --- | 
| Govern | Establish cybersecurity governance, policies, responsibilities and risk management | 
| Identify | Identify critical IT and OT assets, vulnerabilities and cybersecurity risks | 
| Protect | Implement access controls, segmentation, endpoint protection and security awareness |
| Detect | Use SIEM, IDS/IPS, EDR/XDR and OT monitoring to identify suspicious activity | 
| Respond | Apply incident-response procedures, containment and communication processes | 
| Recover | Restore critical services using recovery procedures, backups and continuity planning |
