Amanzi Metro Water: Cybersecurity Assessment

Overview:

This project examines the cybersecurity risks and security requirements of Amanzi Metro Water (AMW), a simulated South African state-owned water utility operating critical IT and Operational Technology (OT) infrastructure. 

The assessment focuses on protecting water-treatment and distribution operations, SCADA and PLC systems, customer and billing information, remote contractor access, cloud services, and third-party suppliers. 

Project Objectives: 
The project applies cybersecurity and risk-management frameworks to the AMW environment, including: 

- ISO 31000
- NIST Cybersecurity Framework (CFS) 2.0
- CIA Triad
- Purdue Enterprise Reference Architecture
- NIST SP 800-61
- MITRE ATT&CK and ATT&CK for ICS
- Business Impact Analysis (BIA)
- Continuity of Operations Planning (COOP)
- IEC 62443

Key Areas: 
- Asset and Risk Management: Identification and classification of critical IT and OT assets and development of an ISO 31000-based risk register.
- IT/OT Security Architecture: Application of the Purdue model, network segmentation, industrial DMZ design and controlled remote access.
- Security Controls: IAM, endpoint security, firewalls, IDS/IPS, SIEM and OT monitoring.
- Detection and Incident Response: Security detection use cases and an incident-reposnse playbook for ransomware and OT manipulation.
- Business Continuity and Recovery: BIA, RTO/RPO, COOP and backup/disaster-recovery strategies.
- Third-party Security: Vendor risk tiering, contratual security requirements and supply-chain security.
- ICS/OT Security: Application of IEC 62443 and Purdue-based security principles to the AMW environment.

Skills Demonstrated: 
- Cybersecurity risk assessment
- IT/OT and SCADA security
- Network segmentation
- Security monitoring and detection
- Incident response planning
