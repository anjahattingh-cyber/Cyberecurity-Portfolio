# Intro to Endpoint Security

## Room Overview

This TryHackMe room introduces the fundamentals of endpoint security and explains how organizations protect endpoint devices from cyber threats.

---

## Learning Objectives

- Understand what an endpoint is.
- Learn why endpoint security is important.
- Identify common endpoint threats.
- Understand how endpoint protection solutions work.
- Learn the role of Endpoint Detection and Response (EDR).

---

## Key Concepts Learned

### What is an Endpoint?

An endpoint is any device connected to a network that can send or receive data, such as:

- Desktop computers
- Laptops
- Mobile phones
- Servers
- Tablets
- Virtual machines

Because endpoints interact directly with users, they are common targets for cyberattacks.

---

### Endpoint Security

Endpoint security is the practice of protecting endpoint devices from malware, ransomware, phishing attacks, unauthorized access, and other security threats.

Common endpoint security solutions include:

- Antivirus software
- Endpoint Detection and Response (EDR)
- Firewalls
- Device encryption
- Patch management

---

### Endpoint Detection and Response (EDR)

EDR solutions continuously monitor endpoint activity to detect suspicious behaviour.

Typical EDR capabilities include:

- Continuous monitoring
- Threat detection
- Incident investigation
- Automated response
- Threat hunting

---

### Common Endpoint Threats

Examples include:

- Malware
- Ransomware
- Phishing attacks
- Credential theft
- Unauthorized software
- Insider threats

---

## Skills Gained

- Understanding endpoint security fundamentals
- Identifying endpoint threats
- Understanding EDR capabilities
- Recognizing common endpoint protection technologies

---

## Why This Matters for a SOC Analyst

SOC Analysts regularly investigate alerts generated by endpoint security tools. Understanding how endpoints are protected and monitored is essential for identifying, analysing, and responding to security incidents.
