# The CIA Triad

## Room Overview

The CIA Triad is the foundation of information security. This TryHackMe room introduced the three core principles that guide the design and protection of secure information systems.

---

## Learning Objectives

- Understand the CIA Triad.
- Learn the importance of Confidentiality, Integrity, and Availability.
- Identify security controls that support each principle.
- Recognize real-world examples of attacks against each principle.

---

## Key Concepts Learned

### Confidentiality

Confidentiality ensures that sensitive information is only accessible to authorized users.

Examples of security controls include:

- Strong passwords
- Multi-Factor Authentication (MFA)
- Encryption
- Role-Based Access Control (RBAC)

Threats to confidentiality include:

- Data breaches
- Phishing attacks
- Unauthorized access

---

### Integrity

Integrity ensures that information remains accurate, complete, and unaltered unless modified by authorized users.

Examples of security controls include:

- File hashing
- Digital signatures
- Version control
- Access permissions

Threats to integrity include:

- Malware
- Unauthorized file modifications
- Data tampering

---

### Availability

Availability ensures that systems and data are accessible whenever authorized users need them.

Examples of security controls include:

- Backups
- Redundant systems
- Disaster recovery planning
- UPS (Uninterruptible Power Supply)

Threats to availability include:

- Denial-of-Service (DoS) attacks
- Hardware failures
- Power outages
- Ransomware

---

## Skills Gained

- Understanding the core principles of information security
- Identifying risks to confidentiality, integrity, and availability
- Recognizing common security controls
- Applying the CIA Triad when analysing security incidents

---

## Why This Matters for a SOC Analyst

The CIA Triad is used daily by SOC Analysts when assessing incidents and determining the impact of security events. It provides a framework for understanding how attacks affect an organization's information systems and helps prioritize incident response.
