# Security Recommendations

## Overview

Based on the findings from the penetration testing engagement, several security improvements are recommended to strengthen the security posture of the healthcare environment. These recommendations focus on reducing attack surface, improving authentication, and increasing resilience against common cyber threats.

---

## Recommendation 1 – Strengthen Authentication

Implement Multi-Factor Authentication (MFA) for all remote access services, including SSH and administrative accounts. MFA significantly reduces the risk of compromised credentials being used to gain unauthorised access.

---

## Recommendation 2 – Disable Unnecessary Services

Only services required for business operations should remain enabled. Unused services should be removed or disabled to reduce the attack surface.

---

## Recommendation 3 – Restrict Network Access

Limit access to critical services such as SSH, FTP and MySQL through firewall rules and network segmentation. Administrative services should only be accessible from authorised management systems.

---

## Recommendation 4 – Keep Systems Updated

Regularly install operating system and application security updates to reduce exposure to known vulnerabilities.

---

## Recommendation 5 – Improve Security Awareness

Provide regular cybersecurity awareness training to help staff recognise phishing emails and other social engineering attacks.

---

## Recommendation 6 – Monitor and Log Activity

Implement centralised logging and continuous monitoring to detect suspicious activity and support incident response.

---

## Key Takeaways

The penetration test demonstrated the importance of combining technical security controls with user awareness. While the laboratory environment was intentionally configured for learning purposes, the assessment highlighted several best practices that would improve the security of a production healthcare environment.
